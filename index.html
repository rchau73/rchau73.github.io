optionsBot: a trading system built by a governed team of AI agents

An automated options-trading system for the Deribit crypto exchange, running on testnet. Claude Code agents write most of the code on a schedule; I designed the roles they play, the rules they follow and the decisions only a person may take.

What the system does

  • Sells BTC and ETH option strangles and manages each through entry, rolls, stops and a kill switch.
  • Treats the exchange as unreliable: rate-limit pools, retries, a circuit breaker, reconciliation every cycle.
  • Journals every decision with a snapshot of the market, which feeds the monitor and the P&L attribution.
  • A Next.js monitor with an assistant that answers from the bot's own docs and journal (RAG, with an evaluation set).

Guardrails that earned their place

  • A secret scan over every commit stopped an agent's test fixture with realistic-looking fake keys.
  • The Reviewer agent blocked a rebuilt PR that would have reverted two merged changes.
  • Every release runs 3 days on the mvp environment before stable; each exception is audited.
  • Delivery is measured with the four DORA metrics per week and environment.

How I work

AI speeds up delivery. Judgement decides what ships.

Decide where people stay in the loop

Before agents write code, I write down which changes are policy. Those wait for a person; everything else flows.

Make every decision explainable

Tickets, reviews and journals carry the reasoning, so anyone can trace why a change shipped or a trade was made.

Measure delivery, not activity

Lead time, deploy frequency, change failure rate and time to restore, per environment. Volume of AI output is not a metric.

Let guardrails fail loudly

Secret scans, coverage floors, soak periods and audited exceptions catch mistakes from people and agents alike.
