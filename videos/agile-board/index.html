Agile with AI agents

A real board and a real ticket: how the AI agents on optionsBot work in Kanban, with epics from an approved product requirements document and a person owning the decisions.

About this page. It shows the agentic approach: how AI agents and people share the work. It is not a detailed account of the implementation. For the scripts, the agents' rules and the full workflow, see the repository on GitHub.

What the film shows

  1. 0:04
    The board. GitHub Projects, with epics from an approved PRD. The PM agent places every new ticket in one of them.
  2. 0:11
    Every story lives in one epic. Epic E1 (issue #134): 21 of 22 stories done, each linked to the pull request that closed it.
  3. 0:18
    The flow. Triage → Ready → Build → Review → Done. Agents move the cards; Blocked waits for a person. 235 cards are Done.
  4. 0:25
    PR #556, opened by the Dev agent. Every pull request states its plan, changes, tests, risk and rollout. This one changes a trading rule, so a person merges it.
  5. 0:32
    PR #551, the Reviewer agent. A blocking finding sends it back: the Reviewer agent read the diff and blocked a PR that would have deleted shipped work.
  6. 0:39
    Agents do the work. A person owns the decisions.
