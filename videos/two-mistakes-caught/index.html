Two AI mistakes in one day

Two mistakes by AI agents on the same day, 30 October 2026. Neither reached the main branch, because the guardrails were already in place.

About this page. It shows the agentic approach: how AI agents and people share the work. It is not a detailed account of the implementation. For the scripts, the agents' rules and the full workflow, see the repository on GitHub.

What the film shows

  1. 0:04
    Mistake 1, 03:44 UTC. The Dev agent opens PR #545 with realistic-looking fake keys in a test file, in a public repository. Go tests and lint pass; the secret scan, which checks every commit, fails and stops the PR.
  2. 0:14
    Mistake 2, 16:18 UTC. An AI rebuild of that PR, made on the wrong base, adds the intended API-key permission check (#538) but also removes two merged features: a clearer connection error (#524) and account deletion (#543). The Reviewer agent reads the diff and blocks it: the PR reverts merged work unrelated to #538.
  3. 0:25
    Fixed at 18:32 UTC. Rebuilt as PR #552 with only the intended change: secret scan clean, nothing deleted, reviewed and merged by me. Neither mistake cost anything.
  4. 0:32
    Agents make mistakes. Guardrails make them cheap.
